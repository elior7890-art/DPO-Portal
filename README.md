# DPO Portal — פורטל ניהול פרויקטי ציות להגנת הפרטיות

פורטל לניהול פרויקטי ציות מול לקוחות DPO: כל לקוח מקבל פרויקט ציות נפרד עם שאלון ציות מודולרי (10 תחומים, מבוסס תיקון 13 לחוק הגנת הפרטיות ותקנות אבטחת המידע), העלאת קבצים, סיווג רמת אבטחה אוטומטי, ספריית מסמכים, וצ'אט פנימי.

מסמך האפיון המלא נמצא ב-[PRD.md](PRD.md).

## מצב נוכחי

זהו כרגע **פרונט-אנד עצמאי בלבד** (`index.html` / `styles.css` / `app.js`, ג'אווהסקריפט רגיל ללא framework), עם נתוני דמו קבועים בקוד לצורך הדגמת הממשק. אין עדיין:
- שרת / בסיס נתונים אמיתי
- אימות משתמשים אמיתי (login מדומה בלבד)
- שמירת קבצים בפועל
- שליחת הודעות בפועל

בחירת ה-stack לצד השרת עדיין פתוחה - ראו סעיף "יישום" ב-[PRD.md](PRD.md).

העיצוב עודכן ב-2026-08-31 מתוך פרויקט Claude Design ("עיצוב ממשקי פרטיות") וכולל כעת:
- פלטת צבעים חדשה (תכלת-כחול בהיר) במקום העיצוב הכהה המקורי
- שני מסכי כניסה נפרדים — לקוח ו-DPO
- שער הסכמה משפטי (תקנון שימוש + מדיניות פרטיות) בכניסה ראשונה של לקוח, עם נעילת אישור עד לגלילה למטה, מלכודת מיקוד (focus trap), ותיעוד ב-`localStorage`
- מסך ניהול "ארגונים ומשתמשים" חדש — יצירת ארגון/משתמש, בחירת תפקיד עם תצוגת הרשאות חיה, ותיקוף דוא"ל בזמן אמת
- מנוע שאלון ציות אמיתי (9 פרקים, כ-40 שאלות עם הסתעפויות, גזירת רמת אבטחה וחובות ציות) בלשונית "שאלון"
- שיפורי נגישות (WCAG 2.1 AA / ת"י 5568): קישור דילוג, ניווט מקלדת בין לשוניות, `aria-live`, ותמיכה ב-`prefers-reduced-motion`

## הרצה מקומית

פתחו את `index.html` בדפדפן, או הריצו שרת סטטי פשוט:

```bash
npx serve .
```

## מבנה

- `index.html` - שלד הדף
- `styles.css` - מערכת העיצוב (טוקנים, כפתורים, כרטיסים, טבלאות, RTL, נגישות)
- `app.js` - כל הלוגיקה: מסכי כניסה, שער הסכמה, רשימת לקוחות, מסך ניהול ארגונים ומשתמשים, מסך פרויקט עם 7 לשוניות (כולל מנוע שאלון הציות המלא), ומרחב פנימי ליועץ
- `PRD.md` - מסמך אפיון המוצר
